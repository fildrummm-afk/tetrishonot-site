## Деплой

Файл `CNAME` содержит `tetrishonot.com` и привязывает домен.

Своего сервера у сайта нет и не требуется.

## Известная проблема с DNS (следить)

В сессии Нейроцеха 2026-07-02/03 разбиралась поломка: в панели Timeweb появлялась
**паразитная AAAA-запись**, указывающая на хостинг Timeweb, хотя сайт живёт на
GitHub Pages. Панель Timeweb при манипуляциях с доменом склонна добавлять A/AAAA на себя.

**Лечение:** удалить лишнюю AAAA либо прописать четыре AAAA GitHub Pages
(`2606:50c0:8000::153`, `8001`, `8002`, `8003`). После любых операций с доменом
проверять `dig A/AAAA tetrishonot.com @ns1.timeweb.ru`.

Отдельно: имеет смысл включить **transfer lock** на домен.
