---

## 🏗️ Как устроен сайт (важно понимать)

| Что | Где | Детали |
|---|---|---|
| **Сам сайт (файлы)** | **GitHub Pages** | Бесплатный хостинг. Репозиторий `fildrummm-afk/tetrishonot-site` |
| **Домен** `tetrishonot.com` | Регистратор **TimeWeb** | Оплачен до **11 мая 2028**, автопродление включено |
| **SSL-сертификат** (замочек 🔒) | Выдаёт **GitHub** бесплатно | Обновляется автоматически, платить не надо |
| **Главный файл** | `index.html` | Весь сайт — это один этот файл |

> ⚠️ Важно: сайт живёт на **GitHub**, а домен куплен в **TimeWeb**. Это две разные площадки. Хостинг TimeWeb для сайта **не используется** — не пытайся заливать туда файлы или покупать там SSL (он там платный и не нужен).

## ✏️ Редактировать текст (без терминала, прямо на GitHub)

1. Зайди на https://github.com/fildrummm-afk/tetrishonot-site
2. Нажми на файл **`index.html`**
3. Нажми карандашик ✏️ (Edit this file) справа вверху
4. Найди нужное место (Ctrl+F / Cmd+F для поиска)
5. Внеси изменения
6. Внизу нажми **Commit changes** → **Commit changes** ещё раз
7. Подожди 1–2 минуты → сайт обновится

> 💡 Если правишь на GitHub, а потом хочешь работать с компа — сначала выполни `git pull` (см. команды ниже), иначе копии разойдутся.

## 🖼️ Заменить фото в галерее

Фотографии в галерее называются `photo2.jpg` — `photo9.jpg` и лежат в папке сайта.

**Чтобы заменить фото:**
1. Переименуй новое фото в то же имя (например `photo3.jpg`)
2. Перетащи его в папку `tetrishonot-site` (старый файл заменится)
3. Открой Терминал и выполни:

```bash
cd ~/Documents/Вайбкодинг/tetrishonot-site
git add .
git commit -m "обновил фото"
git push
```

**Чтобы добавить новое фото:**
1. Положи фото в папку (например `photo10.jpg`)
2. Открой `index.html`, найди секцию `id="gallery"`
3. Добавь строку по образцу:
```html
<img src="photo10.jpg" alt="" class="gallery-img" />
```
4. Сохрани и запушь (команды выше)

## 🎵 Добавить новый сингл в дискографию

Найди в `index.html` место где перечислены синглы (ищи `СИНГЛЫ 2026`) и добавь блок:

```html
<a class="disc-item" href="#" data-album="SPOTIFY_ID" onclick="playAlbum(this);return false;">
  <img class="disc-cover" src="ССЫЛКА_НА_ОБЛОЖКУ" alt="НАЗВАНИЕ" />
  <div class="disc-info">
    <div class="disc-title">НАЗВАНИЕ</div>
    <div class="disc-year">2026 · Сингл</div>
  </div>
  <div class="disc-overlay">Слушать →</div>
</a>
```

**SPOTIFY_ID** — последняя часть ссылки на альбом в Spotify:
`https://open.spotify.com/album/`**`4HPymB4yVFbQc74kUX7dEC`**

## 📹 Добавить видео с YouTube

Найди секцию `id="video"` и вставь:

```html
<iframe width="100%" height="315"
  src="https://www.youtube.com/embed/YOUTUBE_ID"
  frameborder="0" allowfullscreen></iframe>
```

**YOUTUBE_ID** — часть ссылки после `?v=`:
`https://www.youtube.com/watch?v=`**`dQw4w9WgXcQ`**

## 💻 Основные команды Терминала

```bash
# Перейти в папку сайта
cd ~/Documents/Вайбкодинг/tetrishonot-site

# Подтянуть свежую версию с GitHub (делай ПЕРЕД работой, если правил на сайте)
git pull

# Посмотреть что изменилось
git status

# Отправить все изменения на GitHub (= обновить сайт)
git add .
git commit -m "описание что изменил"
git push
```

> ⚠️ После `git push` сайт обновляется через **1–2 минуты**.
> Чтобы увидеть изменения сразу — обнови страницу через **Cmd+Shift+R**

## 🔐 Безопасность (прочитай!)

- **Доступ к GitHub (токен)** хранится в защищённом хранилище macOS (Keychain). При `git push` он подставляется сам — пароль вводить не нужно.
- **НИКОГДА не вставляй токены/пароли в переписки, чаты, сообщения** — только в свой Терминал или в поле на нужном сайте.
- **НЕ прописывай токен прямо в адресе репозитория** (вида `https://ghp_xxx@github.com/...`). Если такое где-то увидишь — это дыра, надо убрать.
- Токены GitHub создаются/отзываются тут: https://github.com/settings/tokens (нужны права `repo`).
- Если токен где-то засветился — сразу **отзови старый** (кнопка Delete) и создай новый. Отозванный токен мгновенно становится бесполезным.

## 🌐 Домен и SSL — важные факты

- **SSL включён**: на GitHub в Settings → Pages стоит галочка **Enforce HTTPS**. Сертификат бесплатный, обновляется автоматически.
- **DNS домена** настроен на GitHub (A-записи `185.199.108–111.153` и `www` → `fildrummm-afk.github.io`). Управляется в кабинете TimeWeb.
- **Не дай домену «уснуть»**: раз в год TimeWeb/ICANN может просить **подтвердить email владельца** — приходит письмо на `fildrummm@gmail.com`. Если не нажать ссылку в письме ~15 дней, домен временно блокируется (`verification-hold`) и сайт перестаёт открываться. Просто вовремя подтверждай email.
- **Не нажимай «Remove»** на домене в настройках GitHub Pages — это сбрасывает сертификат.

## 🆘 Что-то пошло не так?

- **Сайт не обновился** → подожди 2 минуты, потом Cmd+Shift+R
- **Терминал ругается `failed to push ... fetch first`** → сначала `git pull`, потом снова `git push`
- **Браузер пишет «Подключение не защищено»** → проверь на https://github.com/fildrummm-afk/tetrishonot-site/settings/pages, стоит ли галочка **Enforce HTTPS**. Если сертификат «выпускается» — подожди несколько часов (до 24).
- **Сайт вообще не открывается** → проверь в кабинете TimeWeb, не заблокирован ли домен (подтверди email владельца)
- **Что-то сломалось** → напиши мне, разберёмся
